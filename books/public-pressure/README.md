*AI, Anger, and the Revolt Against Institutions That Decide for Us.*

The working thesis is that AI did not invent distrust of technology companies, politicians, insurers, employers, financial institutions, or other centers of power. It changes the pressure gradient around them: automated action, synthetic persuasion, impersonation, and organizing become cheaper while consequential decisions can become harder to inspect, contest, and attach to a responsible person.

This is an intentionally public pre-release proof copied from the committed **Complete draft** on Svyable Desk. It exposes the front matter, opening four chapters, reader-facing source notes, back matter, rights, and research ledger so the argument and evidence can be read together while final release review continues. The complete 23-chapter manuscript remains the Desk release candidate.

This proof is intentionally **not Published**. A final Shelf release will be a separate Git event from a newly verified committed Desk snapshot.
